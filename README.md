# go-vnet

## quic

### 客户端
1. 建立连接，通过验证器获取分配的网卡信息
2. 配置网卡
3. 创建一个默认通信的 stream 服务端暂不转发这个 stream 的数据
4. 开启第二个 stream 作为管理使用，执行接收和发送ping包和对比当前路由和服务路由差异并同步路由
5. 阻塞读取网卡数据
6. 路由网卡数据，如果不在路由表内则丢弃
7. 获取发送到目标的 stream ，如果没有则创建，并通过该 stream 发送到服务端
8. 所有 stream 都有一个协程去读取数据并写入到网卡 func (c *Client) handleRX(rwc io.ReadWriteCloser)

### 服务端
1. 启动服务并接阻塞收受连接以及验证连接
2. 接受三种不同的连接
    a. 第一个 stream 用作默认通信信道，暂不开启转发
    b. 第二个 stream 用作管理通信
    c. 后续 stream 通过发送第一个包握手，由客户端告诉服务端要转发到哪里，服务端在新的协程中读取和转发数据
